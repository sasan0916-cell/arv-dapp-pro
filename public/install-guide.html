📱 راهنمای نصب ARV DApp

🤖 اندروید (Chrome)

۱ سایت رو باز کن
توی Chrome برو به آدرس DApp
۲ منوی Chrome
روی سه نقطه (⋮) بالا راست بزن
۳ Add to Home Screen
گزینه «Add to Home screen» یا «Install app» رو بزن
۴ تأیید کن
دکمه «Install» رو بزن
✅ آیکون ARV میاد روی صفحه اصلی گوشیت

🍎 iOS (Safari)

۱ Safari باز کن
توی Safari (نه Chrome) برو به آدرس DApp
۲ دکمه اشتراک‌گذاری
دکمه اشتراک‌گذاری (مربع با فلش) پایین صفحه
۳ Add to Home Screen
گزینه «Add to Home Screen» رو انتخاب کن
۴ تأیید کن
دکمه «Add» بالا راست
✅ آیکون ARV میاد روی صفحه اصلی

💻 کامپیوتر

۱ سایت رو باز کن
توی Chrome یا Edge برو به آدرس DApp
۲ آیکون نصب
توی نوار آدرس، سمت راست، آیکون نصب (مربع با فلش) ظاهر می‌شه
۳ نصب کن
کلیک کن → Install → تأیید
