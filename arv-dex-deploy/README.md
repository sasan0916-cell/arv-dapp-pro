# ARV DEX Contracts

قراردادهای اختصاصی صرافی غیرمتمرکز ARV:
- ARVPair
- ARVFactory
- ARVRouter

## نصب

npm install

## تنظیم

cp .env.example .env
# ویرایش .env و وارد کردن PRIVATE_KEY و BSCSCAN_API_KEY

## Compile

npm run compile

## Deploy Testnet

npm run deploy:test

## Deploy Mainnet

npm run deploy:main
